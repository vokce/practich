# Практическая работа

Проверка алфавитного порядка строчных букв в пяти массивах.
Python 3.10 или новее. Внешние библиотеки не нужны.

## Запуск

    python code.py

Введите пять строк. Одна строка — один массив. Допустимы `aBc` и `a B c`.
Пустая строка означает пустой массив. В каждом массиве не более 100
элементов. Допустимы только отдельные латинские буквы A–Z и a–z.
Заглавные буквы не участвуют в сравнении. Повторы разрешены.
При отсутствии строчных букв условие считается выполненным.
Программа читает ровно пять строк; последующий ввод не относится к задаче.

## Проверка

    python -m unittest -v

Состав: 12 модульных, 6 интеграционных и 18 системных тестов.
Один модульный тест дополнительно проверяет все 1365 последовательностей
длины от 0 до 5 над алфавитом a, b, A, B по независимому эталону.

`initial_code.py` содержит первоначальную версию с учебными дефектами.
`code.py` — исправленную версию. `scenarios.json` — системные сценарии.
`GITHUB.md` — последовательность действий для части GitHub.
